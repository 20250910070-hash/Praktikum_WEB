PRE-TEST

1. Apa tujuan dari menggunakan version control dalam pengembangan perangkat lunak?

Tujuan utama menggunakan Version Control (Kontrol Versi) dalam pengembangan perangkat lunak adalah untuk mengelola dan melacak setiap perubahan pada kode program agar proses pengembangan lebih terstruktur, aman, dan mudah dikelola.

2. Jelaskan perbedaan antara git add dan git commit!

Perbedaan sebagai berikut:

  1. Git add : git add digunakan untuk memasukkan perubahan file ke dalam staging area (area persiapan) sebelum disimpan sebagai riwayat perubahan.
  2. Git coomit: git commit digunakan untuk menyimpan perubahan yang sudah berada di staging area ke dalam riwayat versi Git secara permanen.

3. Bagaimana cara membuat branch baru di Git?

  1. Periksa branch yang tersedia.
  2. Buat branch baru.
  3. Pindah ke branch baru.
  4. Periksa branch aktif.

POST TEST

1. Apa fungsi dari git merge dalam workflow Git?

Git Merge adalah salah satu perintah dalam Git yang berfungsi untuk menggabungkan perubahan kode dari satu branch ke branch lainnya. Perintah ini sangat penting dalam workflow Git, terutama ketika beberapa pengembang bekerja secara bersamaan dalam satu proyek perangkat lunak. Dalam pengembangan perangkat lunak, biasanya setiap fitur baru atau perbaikan bug dikerjakan pada branch yang berbeda agar tidak mengganggu kode utama (main branch). Setelah pekerjaan selesai dan sudah diperiksa, perubahan tersebut dapat digabungkan ke branch utama menggunakan perintah git merge.

2. Jelaskan cara mengatasi konflik saat melakukan merge!

Merge conflict adalah kondisi ketika Git mengalami kesulitan menggabungkan perubahan dari dua branch karena terdapat perubahan pada bagian file atau baris kode yang sama. Konflik ini biasanya terjadi ketika dua pengembang mengubah bagian kode yang sama dengan isi yang berbeda. Untuk mengatasi konflik saat melakukan merge, pengembang perlu memeriksa bagian kode yang mengalami konflik, menentukan perubahan yang akan digunakan, kemudian menyelesaikan proses merge.

Berikut langkah-langkah untuk mengatasi merge conflict dalam Git:

  1. Periksa status repository
  2. Buka file yang mengalami konflik
  3. Tentukan perubahan yang akan digunakan
  4. Tambahkan file yang sudah diperbaiki
  5. Selesaikan proses merge
  6. Periksa hasil merge

3.Tulis langkah-langkah untuk menambahkan file baru ke repository Git dan melakukan commit?

  1. Cek status repository.
  2. Buat atau salin file baru ke folder repository.
  3. Tambahkan file ke staging area.
  4. Cek lagi apakah file sudah masuk staging.
  5. Lakukan commit dengan pesan yang jelas .
  6. kirim ke remote.
